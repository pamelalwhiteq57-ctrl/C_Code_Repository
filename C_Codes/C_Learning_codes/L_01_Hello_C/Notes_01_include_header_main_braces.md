# C 笔记 01

整理: 2026-11-16
今天讲的只有四件事: include, 头文件, main, 花括号.

## 先记这四句

1. #include <stdio.h> 就是把输入输出的说明书抄到文件开头.
2. .h 是名字清单, 只报名字, 不干活.
3. main 是程序入口, 系统替我调用它, 我不用自己调.
4. 花括号划归属, 还管变量活到哪儿.

## C 程序的骨架

```c
#include <stdio.h>              /* 抄说明书进来 */

int main(void){                  /* 函数头: 返回类型 + 名字 + 参数 */
                               /* 函数体开始 */
    int a;                      /* 语句, 每句都要分号 */
    scanf("%d", &a);
    printf("Hello World\n");
    printf("%d", a);
    return 0;                   /* 交给操作系统 */
}                               /* 函数体结束 */
```

三个小事实:

- #include 那行没有分号, 因为它不是语句, 是预处理指令
- main 就是一个函数: 返回类型 + 名字 + 括号 + 大括号
- 函数体里的每一条语句都要分号

## include

干什么: 编译之前, 把 stdio.h 的内容原样抄到我写这一行的位置.

为什么必须写: C 不认没报备过的名字. 我写了 printf 但没写这行, 它就报:

```
error: implicit declaration of function 'printf'
```

意思就是: 我不认识 printf 这个名字.

名字: std 是 standard 标准, io 是 input / output 输入输出.

三条规则:

- 写在文件最上方
- 用 printf 或 scanf 就写, 一个都不用可以不写
- 要别的工具换名字: math.h, string.h, stdlib.h

和 Python 比: import 是运行时去加载, include 是编译前复印一份.

## 头文件 .h

它就是一份名字清单. 只写有这个东西, 它长什么样, 不写它怎么干活.

判断口诀: 有分号, 没有大括号, 就是声明.

里面长这样一行:

```c
int printf(const char *__format, ...);
```

只要看出它在说 有这么个函数, 返回 int, 括号里放参数 就够了. 括号里那些细节现在不用管.

两个要点:

- 抄进来的是说明书, 不是函数本身. printf 真正的代码早就编译好放在库里了
- 只对这一个 .c 文件有用. 新建一个文件, 还得自己再写一遍 #include

Python 为什么没有: Python 跑到那一行才去找名字, 所以不需要提前交清单.

## 标准库函数

C 语言本身很小. 真正属于这门语言的, 只有语法和几十个关键字: int, if, return 这些. 我调的 printf 并不属于语言, 它是别人写好, 编译好, 放在标准库里的函数.

三样东西连起来看:

- 语言: 语法规则, 我自己写的变量, if, for
- 标准库: 一箱现成的函数, printf 和 scanf 都在里面
- 头文件: 那箱函数的说明书目录

所以一个程序是这样变成 exe 的:

我: 写代码的时候, 写下 printf("hi").
编译器: 编译的时候, 看说明书, 确认名字和参数对得上.
链接器: 最后拼装的时候, 把库里真正的 printf 接进来.

我的 exe 里没有 printf 的源代码, 只有 去库里哪个位置找它 这条线索.

现在我只用过两个, 都在 stdio.h 里: printf 输出, scanf 输入.

同一个部门的还有几个基础的, 先知道名字就行:

- puts: 打印一整行
- putchar: 打印一个字符
- getchar: 读一个字符

这三个都不带 f, 所以不能格式化.

以后会遇到的其他部门, 只要知道有这么回事:

stdio.h 管输入输出, 里面有 printf, scanf.
math.h 管数学计算, 里面有 sqrt.
string.h 管字符串处理, 里面有 strlen.
stdlib.h 管通用工具, 里面有 malloc, rand.

用到哪个查哪个, 不用背. 查的办法: 搜函数名加 cppreference, 或者直接看头文件.

还有一个心态上的提醒: 标准库函数是别人的代码, 行为有固定规则 (比如 printf 不会自动换行). 遇到觉得奇怪的地方, 先查它的规则, 别猜.

## main 函数

它就是一个函数, 四件套齐全. 最前面的 int 是返回值类型.

和 Python 的 -> int 比较:

谁管: Python 的 -> int 运行时不管, 只是备注. C 的 int 编译器要核对.
违反后果: Python 照样跑. C 编译失败, 或被强行转换.

实测: int 函数里写 return 3.9; 编译 0 警告, 结果就是 3. 等于悄悄做了 int(3.9).

为什么必须有 main: 程序启动后, 操作系统先跑一段启动代码, 它最后一句就是调用 main. 没有 main 就找不到入口, 链接失败.

return 0 是给操作系统的: 0 表示一切正常, 非 0 表示出错.

两条容易想错的:

- 语句不能写在函数外面. 函数外面只许放声明和定义
- 不是 只有 main 里的代码才被编译. 所有函数都编译, 只是没人调用的不会执行

## 花括号 {}

作用是划归属: 告诉机器这几行是一伙的. 目的和 Python 的缩进一样.

但机制相反:

靠什么划块: Python 靠缩进, C 靠花括号.
缩进对机器有意义吗: Python 有, 错一格就报错. C 完全没有, 只给人看.

所以 C 里缩进随便, 但要保证两件事:

- 花括号必须配对, 少一个报错会指到文件末尾
- 打了左括号先打右括号, 再往中间填

花括号还管一件事: 变量活到哪儿.

```c
int main(void) {
    int a = 1;              /* 活到 main 结束 */
    {
        int b = 2;          /* 活到这一层的右括号 */
    }
    printf("%d", a);        /* 可以 */
    printf("%d", b);        /* 不行, b 已经没了 */
}
```

三条规则:

- 在哪层花括号生的, 就活到那层右括号死
- 内层能用外层的
- 外层不能用内层的

和 Python 的差别: Python 的 if 和 for 不建作用域, 循环变量会漏到外面; C 的每个花括号都建.
