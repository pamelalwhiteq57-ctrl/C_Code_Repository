# C 笔记 04

2026-11-18

## 概念

计算机里没有字符, 只有数字, ASCII 是数字到字符的对照表, 0 到 127.
C 的 char 就是小整数, 'A' 和 65 是同一个值.
%d 打数字, %c 打字符, 打的是同一个值.
单引号里放一个字符, 双引号里放一串字符.

## 单引号和双引号

这是最容易混的一处.
'A', 一个字符, 值 65, 里面 1 个东西.
"A", 一串字符, 'A' 再加一个结束符, 共 2 个.

单引号里只能放一个字符, 写 'ab' 会警告 multi-character character constant.
双引号里可以放任意多个, 也可以是空的 "".
%c 配单引号, %s 配双引号, 配错会警告.

'A' 是一个数, "A" 是一串字符, 差一个字, 差一个结束符.

## 常用编号

空格是 32.
'0' 到 '9' 是 48 到 57.
'A' 到 'Z' 是 65 到 90.
'a' 到 'z' 是 97 到 122.

大小写正好差 32, 'a' - 'A' 等于 32, 小写转大写减 32 就行.

## 和 Python 比

'A' 是什么, Python 里是长度 1 的字符串, C 里是数字 65.
单双引号, Python 里 '' 和 "" 一样, C 里严格区分.
数字变字符, Python 用 chr(65), C 用 printf("%c", 65).
字符变数字, Python 用 ord('A'), C 里 'A' 本身就有值, 不用转.

最要紧的一条, Python 里 'A' 和 "A" 是一个东西, C 里是两个完全不同的东西.

## 我的程序

```c
printf("%c ", i);
```

把 i 当字符打出来, 后面跟一个空格. i 从 32 走到 127, 打出来就是整张表. for 循环先跳过.

## 一个坑

字符 '5' 不是数字 5, 是 53. 想变成数字要减 '0':
```c
char c = '5';
int n = c - '0';      /* n 才是 5 */
```
