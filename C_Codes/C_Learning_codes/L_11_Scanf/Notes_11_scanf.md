# C 笔记 11

2026-11-19

## 概念

scanf 是 printf 的反方向.
printf 把变量里的值按格式变成字符打出去.
scanf 把键盘上的字符按格式解释成值, 存进变量里.
两者用同一套占位符, 名字里的 f 都是 formatted.

## 为什么要写 &

scanf 要往变量里放东西, 所以得知道变量在哪儿.
& 是取地址, &a 就是 a 的位置, 也就是它的门牌号.
printf 只要值的一份拷贝, 不用去变量那儿, 所以不写 &.
忘了写 &: gcc 会给一条警告, 意思是 scanf 要一个 int 的地址, 我给的却是一个 int.
警告原文: `format '%d' expects argument of type 'int *', but argument 2 has type 'int' [-Wformat=]`
它只是警告, 程序还能编出来, 但运行时会把输入的数字当成门牌号写, 可能直接崩.
单个变量都要写 &, 以后学数组和字符串会遇到不写 & 的情况, 这个先跳过.

## 一次读多个

一句 scanf 就能读多个, 格式串里放几个占位符, 后面就跟几个地址.
`scanf("%d %d", &a, &b);` 输入 3 5, 打印 8.
格式串里的空格表示这里可以有空白, 也可以没有.

## 按格式读, 不按行读

input() 读一整行, 给我一个字符串, 转成整数是我自己的事.
scanf 不看行, 一直读到读不下去为止, 剩下的字符留在输入里, 等下一次来拿.
好处是不用自己转换, 麻烦是上次读剩的东西可能被下一次读到.

## 格式串里的空格

scanf 从左往右走, 把格式串当成一份命令表, 一条一条执行.
格式串里的空格本身就是一条命令, 意思是跳过任意多个空白.
跳的是任意多个空白字符, 不只是空格, 也可以是零个.
空白包括空格, 换行, tab; 我按的回车留下的是换行, 也算空白.
我试了三种写法: 四个空格, 没有空格, 中间换成换行, `scanf("%d %c")` 三种都读对.
能让空白被跳过的一共两套:
一套是占位符自带的, %d 会跳, %c 不会.
一套是我写在格式串里的空格, 写了就跳, 不写就不跳.
%d 两套都有, 所以 "%d%d" 和 "%d %d" 读同样的输入没区别, 空格命令做的 %d 本来也会做.
%c 只有我写的那一套, 所以它前面那个空格不能省.

## %c 的脾气

%d 自己会跳过前面的空白, %c 不会, 下一个字符是什么就读什么.
`scanf("%d%c", &n, &ch);` 输入 `5 A`, ch 读到的是空格, 编码 32.
同样这句输入 `5A`, ch 读到的是 A, 编码 65.
在 %c 前面加一个空格, 两种输入就都能读成 A.
所以 %c 前面那个空格是在说: 读字符之前先把空白清掉.
我试过连续两句 scanf: 先 scanf("%d", &a) 再 scanf("%c", &ch), 输入 5 再按回车, ch 读到的是那个回车, 编码 10, 它没等我输入 A.
因为回车也是一个字符, 第一句读到 5 就停了, 把回车留在输入里, 第二句正好接走.
把格式串写成 " %c" 就会先把回车清掉, 然后再等我输入下一个字符.

## double 要用 %lf

scanf 读 double 必须写 %lf.
打出来的时候 %f 和 %lf 都行.
`scanf("%d %lf %c", &n, &d, &ch);` 输入 `3 2.5 Z` 打出 `3 2.50 Z`.
输入 `100.0` 打出 `100.00`, 因为 %.2f 强制两位, 跟输入写几位无关.

## 返回值

scanf 返回成功读到的个数, 和 printf 返回打出来的字符数是一个路子.
读到一个返回 1, 一个都没读返回 0.
我试过 `int a = 100;` 然后输入 abc: 返回 0, a 还是 100, 读不到就不动原来的值.
所以给变量一个初值再 scanf, 读失败时手里至少是个确定的数.

## 和 Python 比

input() 读一整行, 返回字符串, int() 是我自己加的.
scanf 直接按占位符把字符变成数, 所以要多给一个地址, 告诉它存哪儿.
Python 不用地址, 是因为它把转换和赋值拆成了两步, 本来就知道抄给谁.

## 结论

scanf 是按格式把输入变成值, 放进我给的地址里.
格式串决定怎么读, 地址决定放哪儿, 两个都对上才读得对.
