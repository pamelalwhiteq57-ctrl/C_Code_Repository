# C 笔记 08

2026-11-19

## 概念

类型就是相似的数据所拥有的共同特征.
编译器只有知道了数据的类型, 才知道怎么操作这份数据.
数据类型分两大类: 内置类型, 直接就有; 自定义类型, 我自己设计.

## 内置类型

字符型: char, 存一个字符.
整型: short, int, long, long long, 存整数, 越往后能装的数越大.
浮点型: float, double, long double, 存小数.
布尔类型: _Bool, 只存真和假.

内置类型是 C 语言自己带好的, 我写个名字就能用, 不用自己定义.

## 整型这几个其实都带 int

short 的全名是 short int.
long 的全名是 long int.
long long 的全名是 long long int.
写的时候 int 可以省掉, 平时就写 short, long, long long.
int 是这一组里的标准款, 不长不短, 最常用.
所以短整型这一支, 只有 int 是可以单独写的那个, 也是我最先该用的那个.

## _Bool 为什么单列

C 里的布尔类型真名就叫 _Bool, 前面带一个下划线.
用 %d 打出来是 1 和 0, 没有 True 和 False 这两个词.
平时书上看到的 bool, true, false 来自另一个头文件, 那个还没学到, 先记 _Bool.
它和整型分开算, 是因为它只回答真和假, 不拿来做加减.

## 自定义类型

数组, 结构体 struct, 枚举 enum, 联合体 union.
这四个都要我自己定义出来才有, 所以叫自定义类型.
数组和我之前用过的 char 数组是一回事, 其余三个只记名字, 学到再展开.

## 我的程序

```
char c = 'A';                 打出来 A
short s = 100;                打出来 100
int i = 2026;                 打出来 2026
long l = 123456;              打出来 123456
long long ll = 1234567890123; 打出来 1234567890123
float f = 3.14;               打出来 3.140000
double d = 3.1415926;         打出来 3.141593
long double ld = 3.14159265;  打出来 3.141593
_Bool b = 1;                  打出来 1
```

浮点打出来的小数位数比我写的少, 是 %f 默认只留六位小数, 不是值变了.
long 要用 %ld, long long 要用 %lld, long double 要用 %Lf. 占位符和类型对不上, 打出来就不对.

## 和 Python 比

Python 定义变量不用写类型, C 必须写, 因为编译器要先知道怎么操作.
Python 的 int 能一直变大, C 的 int 装不下就是装不下, 要先挑够大的类型.
Python 的 float 本来就是双精度, 没有 float 和 double 之分, C 要自己挑.
Python 的 True 和 False, 在 C 里是 _Bool, 存成 1 和 0.

## 结论

内置类型直接就有, 自定义类型要我自己定义.
内置类型记四组: char, 四种整型, 三种浮点, _Bool.
整型那一支除了 int, 全名后面都还跟着一个 int, 只是平时省掉不写.
