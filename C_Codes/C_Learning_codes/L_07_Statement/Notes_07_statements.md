# C 笔记 07

2026-11-19

## 概念

C 的代码是一条一条语句构成的, 每条语句以分号结尾.
语句分五类: 空语句, 表达式语句, 函数调用语句, 复合语句, 控制语句.
前四类我在代码里见过, 第五类只见过名字.

## 空语句

一个分号就是一条空语句.
哪里需要一条语句, 但这条语句不用做任何事, 就放一个分号.
我程序第 3 行那个单独的分号就是.

## 表达式语句

表达式后面加一个分号.
b = a + 5;
赋值, 加减, 这类运算加上分号都算.

## 函数调用语句

函数调用后面加一个分号.
printf("Hello\n");
函数调用本身也是表达式, 讲义单独列一类, 是因为调用它通常不是为了拿返回值.

## 复合语句

一对大括号里的代码构成一个代码块, 这个代码块就是复合语句.
main 后面那对大括号里的所有语句, 合起来是一个复合语句.
里面还能再套大括号, 套一层就是一个新的复合语句.

## 控制语句

控制语句管程序怎么执行, C 语言一共九个.
条件判断: if, switch.
循环: do while, while, for.
转向: break, goto, continue, return.
这九个还没写, 先记名字.

第 3 行的一个分号, 空语句.
