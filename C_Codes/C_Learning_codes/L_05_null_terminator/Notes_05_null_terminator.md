# C 笔记 05

整理: 2026-11-18
这次只有一件事: 字符串结尾的 \0.

## 先记这几句

1. \0 是读取的停止标记. printf("%s") 从头往后读, 读到 \0 才停.
2. "abc" 自带 \0, {'a', 'b', 'c'} 不带.
3. 带不带 \0 看写法, 不是 C 自动补上的.
4. 读过头了 C 不报错, 读出来是什么, 我不能预期.

## 我那个程序为什么打出 abcabc

```c
char arr1[] = "abc";
char arr2[] = {'a', 'b', 'c'};
printf("%s\n", arr2);
```

arr2 里没有 0, printf 不会停, 一直往后读, 读到了 arr1 的 a b c,
再读到 arr1 末尾那个 0 才停下来, 所以打出 abcabc.

arr2 后面是谁, 我决定不了. 换台机器, 后面就是别的东西.

## 双引号和大括号

"abc": 自带 \0, 打出来 abc.
{'a', 'b', 'c'}: 不自带 \0, 会一直往后读, 读到碰上一个 0 为止.

## 和 Python 对照

Python: 字符串自己存长度, 读过头了报 IndexError.
C: 靠结尾的 \0, 读过头了不报错, 照常给出一个数.

Python 的报错在替我兜底, C 没有这层兜底.

## 补上 \0 的写法

```c
char arr2[] = {'a', 'b', 'c', '\0'};
```

'\0' 和 0 是同一个东西, 只是写法不同. 原来的双引号写法 "abc" 本来就有, 不用补.

## 今天记住这一句

\0 是字符串的停止标记. 双引号写法自带, 大括号写法我自己补.
