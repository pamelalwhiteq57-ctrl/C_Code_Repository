# C 笔记 05

2026-11-18

## 概念

\0 是读取的停止标记, printf("%s") 从头往后读, 读到 \0 才停.
"abc" 自带 \0, {'a', 'b', 'c'} 不带.
带不带看写法, 不是 C 自动补的.
读过头了 C 不报错, 读出什么我没法预期.

## 我的程序为什么打出 abcabc

```c
char arr1[] = "abc";
char arr2[] = {'a', 'b', 'c'};
printf("%s\n", arr2);
```

arr2 里没有 0, printf 不会停, 一直往后读, 读到 arr1 的 a b c, 再读到 arr1 末尾那个 0 才停下, 所以打出 abcabc.
arr2 后面是谁我决定不了, 换台机器后面就是别的东西.

"abc" 自带 \0, 打出来 abc.
{'a', 'b', 'c'} 不带 \0, 会一直往后读, 碰上一个 0 才停.

## 和 Python 比

Python 的字符串自己存长度, 读过头报 IndexError.
C 靠结尾的 \0, 读过头不报错, 照常给一个数.
Python 的报错在替我兜底, C 没有这一层.

## 补 \0

```c
char arr2[] = {'a', 'b', 'c', '\0'};
```

'\0' 和 0 是同一个东西, 两种写法. 双引号写法 "abc" 本来就有, 不用补.

## 结论

\0 是字符串的停止标记, 双引号写法自带, 大括号写法我自己补.
