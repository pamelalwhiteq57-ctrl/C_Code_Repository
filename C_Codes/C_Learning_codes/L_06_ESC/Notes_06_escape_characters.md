# C 笔记 06

整理: 2026-11-18
这次学的是转义字符: 反斜杠开头的两个字符, 用来表示一个打不出来、或者有特殊含义的东西.

## 讲义原文

\? : 在书写连续多个问号时使用, 防止他们被解析成三字母词, 在新的编译器上没法验证了.
\' : 用于表示字符常量'
\" : 用于表示一个字符串内部的双引号
\\ : 用于表示一个反斜杠, 防止它被解释为一个转义序列符.
\a : 警报, 这会使得终端发出警报声或出现闪烁, 或者两者同时发生.
\b : 退格键, 光标回退一个字符, 但不删除字符.
\f : 换页符, 光标移到下一页. 在现代系统上, 这已经反映不出来了, 行为改成类似于 \v.
\n : 换行符.
\r : 回车符, 光标移到同一行的开头.
\t : 制表符, 光标移到下一个水平制表位, 通常是下一个 4/8 的倍数.
\v : 垂直分隔符, 光标移到下一个垂直制表位, 通常是下一行的同一列.

## 我代码里这几行

```
printf("(Are u OK\?\?)\n");    打出来: (Are u OK??)
printf("%c\n", '\'');          打出来: '
printf("%s\n", "\"");          打出来: "
printf("%s\n", "\\");          打出来: \
printf("\a\n");                打出来: 一声提示音, 没有可见字符
```

\? 是为了防止连续的 ?? 被当成特殊记号, 新的编译器上直接写 ?? 也没事, 加 \ 只是老习惯.
\' 和 \" 是因为引号本身有含义, 想在字符或字符串里放一个引号, 就得先用 \ 把它变成普通字符.
\\ 是因为反斜杠本身是转义的开关, 想打出一个反斜杠, 就得写两个.

## 光标类的三个

```
printf("abcdef\b\bqt\n");   终端里显示: abcdqt
printf("abcdef\rxx\n");     终端里显示: xxcdef
printf("a\tbc\tdef\tghi\tyyyyy\tw\n");
```

\b 是光标往回退一格, 但不删字符. 退两格后打 q 和 t, 正好盖掉原来的 e 和 f, 所以看到 abcdqt.

\r 是光标回到这一行的开头. 回去以后打 xx, 盖掉开头的 a 和 b, 所以看到 xxcdef.

\t 是把光标推到下一个制表位 (8 的倍数), 所以每段之间对齐成一个个宽格子. 我在中间塞了个 yyyyy, 把那一列的宽度撑开了, 后面的 w 就被推到了下一格.

## 和 Python 对照

\n \t \a \b \r 这些写法 Python 里一模一样, 都是反斜杠加字母.
\? 是 C 独有的, 因为只有 C 有"三字母词"这个历史问题, Python 里直接写 ?? 就行.
Python 的 print 遇到 \b 和 \r 也是交给终端去处理, 表现和 C 一样.

## 今天记住这一句

反斜杠是转义的开关: 它后面那个字符不按字面意思算, 而是按约定变成另一样东西.
